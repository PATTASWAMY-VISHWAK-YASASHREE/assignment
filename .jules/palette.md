## 2024-05-23 - Immediate Validation Feedback
**Learning:** Users typing JSON or code often struggle with syntax errors that are only caught upon submission, leading to frustration. Immediate feedback (e.g., on blur) helps them correct errors in context without breaking their flow.
**Action:** When designing inputs for complex data formats (like JSON), implement client-side validation that triggers on blur or pause, providing specific error messages before the user attempts to submit.
